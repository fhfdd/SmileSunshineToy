SmileSunshineToy
 
项目简介
 
本项目是基于 WinForms + .NET Framework 4.7.2 实现的玩具工厂简易ERP管理系统，为课程实训项目。
系统实现销售、生产、采购、库存、物流、人员、供应商客户、财务收支等基础业务流程，用来模拟中小型玩具制造企业内部资源的线上管理，仅作为练习原型，不可直接用于生产环境。
 
技术栈
 
- 运行框架：.NET Framework 4.7.2
- 前端界面：Windows Forms（WinForms）
- ORM：Entity Framework 5.0
- 数据库：MySQL
- 第三方组件：- PDFsharp：表格数据导出PDF报表
- Microsoft.Extensions.DependencyInjection：简易依赖注入
- Microsoft.Extensions.Logging：基础日志
 
系统架构
 
项目采用四层分层架构，将界面、业务、数据访问、数据库做分离，避免业务逻辑直接写在UI事件内。
 
1. 数据库层（MySQL）
通过SQL脚本完成建表与初始化，存储物料、成品、订单、生产、人员、财务等全部业务数据。
2. 数据访问层（DAL）
使用 EF5 作为ORM框架，通过实体上下文  Model1.Context  完成实体与数据表映射，封装基础数据库读写，屏蔽原生SQL。
3. 业务逻辑层（BLL / Service）
以 Service、Manager 类封装各模块业务规则，例如库存校验、发货处理、订单流转等，处理业务判断与流程控制。
4. 表现层（UI‑WinForms）
各个 Form 窗体作为人机交互入口，负责接收用户操作、展示数据，调用业务层接口完成功能。
 
公共基础组件（系统底座）
 
项目封装通用工具类，供全部业务窗体复用，减少重复CRUD代码：
 
-  DataGridManager ：DataGridView通用管理器，封装表格加载、查询、新增、编辑、删除通用操作。
-  FormNavigationManager ：窗体跳转、弹窗提示、页面生命周期统一管理。
-  UserSession ：登录会话管理，保存当前登录用户信息，实现基础角色权限控制。
-  Configuration ：系统配置读取（数据库连接等）。
-  TextPdfExporter ：报表PDF导出工具。
 
功能模块
 
1. 仪表盘（首页）：系统总览导航，根据登录角色展示可用功能菜单
2. 销售管理：新建销售订单、订单查询
3. 生产管理：生产计划新增、计划总览、生产入库
4. 库存管理：原材料管理、成品管理、仓库管理
5. 采购管理：采购业务维护与查询
6. 研发看板：玩具产品研发信息看板
7. 物流配送：发货管理、物流业务总览
8. 基础资料：客户管理、供应商管理、员工管理
9. 财务管理：收款登记、付款登记
10. 账号权限：用户登录、用户资料维护、会话权限校验
 

部署运行
 
本项目为课程原型，未做完善工程化处理。
 
1. 环境准备- Windows 系统，安装 .NET Framework 4.7.2
- 部署 MySQL 数据库，执行提供的 SQL 初始化脚本，完成建表与基础数据导入。
2. 修改数据库连接配置，根据本机数据库地址、账号、密码更新连接信息。
3. 使用 Visual Studio 打开解决方案，还原NuGet依赖包，编译项目，启动程序。
4. 使用账号登录进入系统。
 
注意：当前版本连接配置存在硬编码风险，如需更换运行环境，需要修改源码后重新编译。
